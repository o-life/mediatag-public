# AI短剧生成过程审计标准标签映射表 (v1.0)

本文档用于审计AI视频（如 Sora, Kling, Luma 等）的生成质量与技术特征，将 VLM 的视觉分析结果归一化为技术审核指标。

## 🛠️ 归一化原则
- **技术导向**：优先记录“生成错误”而非“故事内容”。
- **粒度控制**：将具体的形变描述（如“手指变成了六个”）统一归类为 `物理崩坏`。
- **纯净值**：仅写入标签值，不含维度前缀。

---

## 🏷️ 标准维度定义

### 1. [生成质量] -- Generation Quality (Critical)
*衡量视频是否可用，主要捕捉 AI 生成的常见伪影。*

| 标准标签 | 包含的同义词/分析项 | 说明 |
| :--- | :--- | :--- |
| **闪烁** | Flickering, 亮度跳变, 画面不稳 | 像素级或色调级的快速明暗闪烁 |
| **形变** | Morphing, 物品融合, 结构扭曲 | 物体在运动过程中发生非物理性的形态改变 |
| **物理崩坏** | Physics Error, 重力异常, 穿模 |- 例如：人体穿墙、物体无端漂浮、肢体交叠 |
| **细节丢失** | Loss of Detail, 模糊化, 涂抹感 | 画面局部出现严重的低分辨率或算法涂抹痕迹 |
| **逻辑矛盾** | Logical Error, 空间跳变 |- 例如：人物瞬间位移、物体凭空出现/消失 |

### 2. [视觉风格] -- Visual Style
*定义生成内容的艺术方向。*

| 标准标签 | 包含的同义词/分析项 | 说明 |
| :--- | :--- | :--- |
| **写实** | Photorealistic, 真实感, 电影级写实 | 接近真实摄影的视觉效果 |
| **二次元** | Anime, Manga, 赛璐璐 | 明显的动漫或插画风格 |
| **电影感** | Cinematic, 高对比度, 宽幅 | 具有明显专业调色和构图特点 |
| **超现实** | Surreal, 梦幻, 抽象 | 包含非逻辑的艺术化视觉元素 |

### 3. [镜头语言] -- Cinematography
*描述 AI 对相机运动的模拟能力。*

| 标准标签 | 包含的同义词/分析项 | 说明 |
| :--- | :--- | :--- |
| **动态运镜** | Dynamic Camera, 摇移, 轨迹追踪 | 镜头有明显的路径移动或复杂旋转 |
| **稳定特写** | Stable Close-up, 面部聚焦 | 高度稳定的近距离拍摄，无明显晃动 |
| **全景扫描** | Wide Shot, Pan, 环境展示 | 大范围的环境捕捉 |
| **第一视角** | POV, 第一人称 | 模拟主观视觉 |

### 4. [一致性] -- Consistency (Sora-Level Metric)
*衡量长视频在时间轴上的稳定性。*

| 标准标签 | 包含的同义词/分析项 | 说明 |
| :--- | :--- | :--- |
| **面部稳定** | Stable Face, ID一致 | 在不同镜头中人物面貌保持高度统一 |
| **服装跳变** | Outfit Jump, 衣服变换 | 角色在运动或切镜后衣服颜色/款式发生改变 |
| **背景漂移** | Background Drift, 环境不稳 | 背景元素在移动时产生拉伸或位置偏移 |
